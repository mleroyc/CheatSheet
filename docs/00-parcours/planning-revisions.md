# Planning de révisions

Calendrier indicatif après l'étude initiale d'une vulnérabilité :

| Moment | Travail |
|---|---|
| Jour 0 | Répondre aux questions sans notes et résoudre un premier lab. |
| Jour 1 | Revoir les questions échouées et expliquer les mécanismes de mémoire. |
| Jour 3 | Refaire un raisonnement de test sans consulter la méthodologie. |
| Jour 7 | Revoir les blocages du journal et retester les points faibles. |
| Jour 14 | Traiter un scénario modifié ou une variante. |
| Jour 30 | Évaluer la maîtrise globale et décider si le sujet reste à réviser. |

Ces intervalles sont un point de départ, pas une garantie de mémorisation. Revois plus tôt une notion qui reste fragile ; espace davantage les sujets que tu maîtrises réellement.
