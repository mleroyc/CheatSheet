# Journal de labs

Un compte rendu par lab. Consigne les hypothèses, les essais significatifs, les résultats, le niveau d’aide, le blocage principal et la leçon généralisable.

## Modèle recommandé

Utiliser le [modèle de compte rendu](template.md) et copier une page par lab. Les comptes rendus doivent être classés par famille ou plateforme, puis reliés depuis les pages de vulnérabilité concernées.

## Règles de consignation

- Séparer action, observation, interprétation et décision.
- Ne pas enregistrer les secrets ou identifiants réels.
- Noter le niveau d’aide le plus élevé utilisé.
- Terminer par une leçon transférable et une prochaine action.
